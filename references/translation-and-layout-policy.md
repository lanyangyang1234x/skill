# 新工程与版式

用于新建数学译稿的工程组织，以及引用、字体或版式专项修改。内容保护与每批工作顺序以 [主入口](../SKILL.md) 为准；术语、中文改句、图形、勘误和发布分别由对应专题维护，不在这里重复整套审校要求。

## 初始化

- 每个新任务按[主入口](../SKILL.md#每个新任务先确认模板)询问本次模板；当前请求已选模板或明确保持现有版式则直接采用，同一任务继续不重问。不自动默认 Sage-Olive。等答复期间可读源和盘点，不先初始化或迁移。确认后完整复制所选模板的字体、样式与必要资产，不将示例正文当成译稿内容；既有工程使用真实主文件与构建方式。
- 源题名、作者与版本信息依当前原书。译者、审校者、工具/模型等署名只用已确认信息，未知可留空/匿名；不因缺署名停下译写。若用户要求署名但具体姓名无法推定，再询问该项。
- 可靠 Markdown 的标题、正文、公式、图路径、脚注、锚点和页标记按源文单元转换为真实 TeX。只对缺失、冲突、乱码或可疑部分补提取/OCR；保留原转录稿。
- 长项目复用已有台账与构建入口。按内容组织章节，不为每个审阅批次强拆单文件；并行写入冲突时由协调者应用局部修订或拆出合理的独立章节。
- 封面、版权页、目录等默认跟随所选模板；省略目录或匿名署名属于用户可指定的呈现选择。不要为验证器的默认检查额外生成原书没有的正文结构。

## 引用与编号

先建立“源书可见编号 → 数学对象 → 实际 TeX 标签”映射，再转换手打引用。罗马章号、带撇编号、附录号、重号和手设计数器须按上下文解析；普通年份、举例数字、区间和复形移位不能按引用替换。

- 在真实目标建立 `\label`，用 `\ref`/`\autoref`、`\eqref` 或保留源显示文字的 `\hyperref` 引用。
- 显示编号依源版本或用户已确认的编号规则。`根据定理~\ref{thm:xxx}` 与 `由式~\eqref{eq:xxx}` 的目标须对应原对象；不能链接到附近条目来消除未定义警告。
- 未译、缺失或歧义目标单独登记。不能虚构目标、隐藏未解决引用或把现有内部标签批量改名。
- 最终同时核可见编号和 PDF 实际点击目标；目录、术语索引、习题/答案及文献导航按源材料和模板支持范围检查。

多组参考文献或手打文献引用另读 [审计证据与发布](audit-evidence-and-release.md)。模板已有 `thebibliography`/`mybibliography` 或 BibTeX/Biber 流程就沿用，不因模板缺少示例文献而补造书目。

## 字体、标题与分页

新中文工程执行[字体约定](font-policy.md)：Fandol 宋体正文/证明/例题、仿宋定理陈述、楷体术语强调；内页中文标题用 Noto Serif CJK SC SemiBold（600），西文标题与编号用 CMU Serif Bold。西文正文用 CMU Serif、数学用 Computer Modern/AMS/RSFS，正文12pt、1.3倍行距；译校注标题仍用宋体粗体。模板控制封面构图、色彩、框和导航；既有工程遵从本次授权，不因字体修订替换封面或定理框。

三个中文入口用 `\usepackage[chinese]{chinese-headings}` 接入独立标题样式，共享 `portable-math-fonts.sty` 保持原配置。附加样式默认及 `[english]` 不作修改，英文等非中文原语言重排不启用中文选项。环境名称与编号分别依对应正文正体“设”的字面中心校准，参照字体不能继承标题粗体；保留字号、字宽及原生 CJKglue，不固定下移 `0.08em`，不冻结整名称的可伸缩字间距。校准后核受影响首行与邻页，保护正文、公式、编号内容和导航。具体实现与验收见[字体约定](font-policy.md#环境名称与编号的字面中心)。

字体必须显式映射常规/粗体/斜体，字体文件与许可随项目携带，以 `fonts/` 等相对路径引用；不能依赖本机绝对路径、私有系统字体或静默 fallback。最终检查标题、定理标签、证明、公式、脚注、封面的实际字体继承，以及缺字、字体替代和 PDF 嵌入；编译成功不足以证明字体正确。

保留源派生 Latin 文字的拼写与大小写。模板的 `Chapter`/`Proof` 等界面标签样式不能把源标题、人名、图注或署名变成全大写或 small caps；必要时在相应源字符串局部解除继承样式。中文标点按句法使用，原语言引文和公式/代码语法保留其需要的符号。

前言与首章的转场、长证明结束、公式/图/脚注附近的分页须实际看页。遇到排版冲突时调整允许的布局，不删数学内容或强制把整个长段落塞入不可分页盒子。

图形按原书核标签、箭头格式与位置，表格核行列、边界、合并格、符号与对齐；只要求表格外观一致时采用适当原生表格环境，不凭空把正文表格改成图片。禁止用 `resizebox`、`scalebox`、`adjustbox` 或整图 `scale` 压小图/表格来通过版面检查。调整坐标、间距或授权版面后看最终页；用户要求段落布局及行间公式时机同原书时，同步核其位置，不自行把行间公式改为行内。

## 公式、表格与图式的局部排版

以实际阅读问题选择改法。用户允许优化重排时，不必复刻原书的坏断行；用户要求还原原书外观时，遵从其约束。下面的检查用于已授权版式范围，不授权改写公式或扩大任务。

- **异常空白先找原因。** 区分正文两端对齐拉伸、长行内数学盒不可断、`\mbox`/不可断空格，以及人为加入的 `\hfill`、`\quad`、宽列距。等号两边空白异常时，检查 `aligned`/`array` 是否把一条等式误拆到多组对齐列；不要把本来正常的关系符间距一律压紧，也不用全局 `\sloppy` 或负间距掩盖问题。
- **按数学结构断行。** 简短条件、对象说明和能自然随正文换行的公式留在行内；长式确实撑坏正文时，可改为行间式，或在等号、关系符、加项边界合理分行。行数服从式子结构和可读宽度，不把每个条件都单独陈列，也不为减少行数把过长部分硬塞一行。`and` 等连接词按句法放在相应两项之间，不能漂到错误的等式链中。
- **版式改后再核公式。** 逐项比对符号、指标、正负项、各项顺序、等号/不等号、量词、连接词及括号配对和作用范围。长括号跨行时尤其核查；不能把括号外的项收进括号，或让下一行看似属于另一条件。保留公式编号和引用目标，再看最终页的断行、标点及上下文承接；无溢出警告不代表排法合适。
- **表格先排清行列与净空。** 对齐同列内容、基线与对应行，检查矩阵上下括号、分式、上下标和表线是否相碰。需要时局部调整行高、单元格上下留白、列距或分组，保留原来的行列对应与合并格语义；不要只加大整表行距或缩小整个表来代替逐处处理。
- **长标签要有足够的箭身。** 标签超出短箭时，原生加长箭或调整对应列距，再定位标签；标签应与所属箭清楚对应、不压线，也不因避线远离该箭。核查长限制映射、复合映射以及正合列等线性图式，不能只检查有 `figure` 环境的图。推出、拉回等方块保留原书的语义标记与方向。具体重建仍按[图形验收](book-completion-and-figure-qa.md#native-tikz-constraints)。
- **按具体几何调整间距。** 原书或用户明确要求圆形的圈，采用圆形坐标安排顶点与弧线，不能仅用多边形连线代替。保留已确认的箭头样式；直箭、弯箭、自环的端点净空分别检查，避免一项全局参数把原来合适的直箭也改坏。标签、箭头与顶点既不相碰，也不无故拉远。

用户明确要求“同类问题全书修订”时，在其授权范围内检索相同宏、图式和排版成因，逐处判断并核最终落页，不能只修截图所在处。仅要求局部修订时，检查该处及受影响邻页；检索命中也不是机械全局替换的许可。

## 导航与术语索引

新建 Project v2 默认保留其 `MidnightBlue` 内部/目录/URL 链接与 `BrickRed` 文献链接、无边框显示及习题/答案导航。其他模板按各自接口；既有项目保留既定链接颜色，不把文献颜色改动扩展到个人蓝字批注。

书籍或篇幅较大的讲义维护适当的术语账及索引/词汇表，记录源词、确定的译名和定位；短论文按实际需要，不为凑结构新增索引。更新现有索引时同步改动术语和页链接，不重建其版式。

**逻辑编号与页码分开处理。** 保护原书定理、公式、练习等编号，不等于保留原书页码。翻译、重排或版式调整后，目录、索引、图表目录及指向本版内容的页码必须由当前 TeX 目标自动生成；可用索引工具链或词条实际出现处的标签与 `\pageref`。不得手抄旧页码、仅用原页到新页的偏移换算，或因蓝色超链接能跳转就认定索引正确。明确引向外部原书的引用可保留原页码，但应显示“原书第…页”等来源限定，不能混作本版页码。

**索引目标落在词条本身。** 原书一页在重排后可能跨多个新页；源页锚点和源页映射只作查找线索，不能直接把源页起点的 `\pageref` 当成该页所有词条的页码。逐条找到实际出现、定义或原索引指定讨论的位置，在对应正文设置索引标记或独立标签。保留多处出现、子项和范围的语义；不能链接到附近条目来消除未定义目标。

**可见页码、PDF 页标签和落点分别核验。** 对每条本版页码引用，核对显示页码是否等于目标所在页的印刷页码/PDF page label（包括罗马页码等编号体系），再核实际落点是否对应词条或对象。PDF 物理页序号不能直接当印刷页码。机器可全量检查数字、标签和目标页的一致性；目标语义和索引换行、分栏须按任务范围实际查看。未闭合的条目记为未完成，不能以“原书编号保留”或“链接有效”替代验收。

先让正文分页与引用稳定，再生成索引等派生材料并继续构建至目录/索引稳定。正文或布局随后变化，应重新生成页码并复核受影响条目；最终 ZIP 的干净解压重建也须产生相同的索引页码与落点，见[独立重建](audit-evidence-and-release.md#最终-zip-的干净解压与比较)。模板验证器的固定预编译轮次只用于完成默认构建，不证明任意工程已经收敛；最终以连续构建的产物/警告与 PDF 实际结果判定。

## 验收转接

新译稿按主入口分别记录实质检查；现有全文审计读 [既有项目审计](existing-project-audit.md)。图形含本地图式与图片，读 [图形与成书](book-completion-and-figure-qa.md)。交付最终包读 [独立重建](audit-evidence-and-release.md)。只改几个引用或字体时验收相应影响，不宣称其他维度的全书审计完成。
