# Reader Notes and Source Errata

用于既有译校注审查、原书疑点处理、授权更正及脚注转换。先读取本项目最新用户约定、当前工程和已有注记；历史报告帮助定位，不替代本轮源书核查。配色、字号、标题形式、框线和脚注样式均为项目设置，不从其他书复制为默认。

## 区分文字身份与授权

| 身份 | 处理方式 |
|---|---|
| 译稿错译、错抄、漏条件或符号 | 在本次修订范围内对照原书直接修正；需要给读者解释时才增加译修说明 |
| 已核定的原书笔误、缺条件或证明缺口 | 原书与译稿错误分开登记；用户已授权改正文时按该约定更正并留可追溯注记，无此授权时先记报告，不静默改源意 |
| 尚未核定的数学疑点或源图不可辨处 | 保留不确定性、源位置和所缺证据，不标为已解决；“与原书一致”不等于数学结论已经独立证明 |
| 译者/审校者新增解释或补证 | 仅在授权范围新增，与原文译文分开，说明它是补充及所据来源 |
| 用户个人批注，包括蓝字 | 保护原文字、位置关联、颜色和锚点；可以在报告回答疑问，不将其改成审校者注记或擅删 |
| 编译、渲染、归档等过程记录 | 放审计报告、验收台账或工程说明，不混入书中读者注记 |

授权和展示方式以会话最新决定为准。早期“只写报告”可被后续“修改正文并加注记”更新；曾经允许某种颜色也可被后续否定。已有明确授权时直接继续，不重复索取同一批准。用户只要求换色、换字体或转脚注时，不顺便重写数学内容、增加补证或替换定理框。

## 给读者的注记包含什么

对原书更正，至少交代：原书的印刷页码/条目、原写法、当前修正，以及修正理由或必要依据。引用原写法应短而准确，覆盖读者理解差异所需内容；含公式时保留关键条件和符号。单纯说“已修订”“经核验正确”不能代替理由。

审计表另记 PDF 物理页、原书版本/快照、TeX/注记锚点和当前成书页，区分这些坐标。印刷页码无法取得时明示使用 PDF 页号，不能把两者混写。重新分页后用锚点刷新成书定位，不覆盖原书位置。

- 明确区分原书的结论、译稿处理和新增论证。外部补证不说成原证明的翻译；引用可点击来源或文献，保留原题名、人名和必要源词。
- 写“原书快照未见该箭线”与写“原作者漏画箭线”需要不同证据。扫描淡线、遮挡或空白源页不足以断定作者失误；不能凭绘图偏好补出未确认的节点或箭头。
- 保留量词、方向、限定、否定及证据强度。对尚无足够依据的候选不为了语言简洁删除“疑似”“尚待核定”等真实状态。
- 原文术语不是每条注记都需附英文整句。只保留判断差异必要的源词；人名、数学记号、原题名和文献证据按其身份保留。
- 把“逐像素比对”“已归档”“旧锚点保留”“某工具生成”等过程移入报告。正文旁只放读者理解修改所需的信息。
- 注记中提到现有定理、公式或参考文献时使用真实链接并核实际落点；缺失或暂缓的目标如实登记，不创建假跳转。

复查既有注记时逐条记录保留、措辞修订、数学重核或待确认。只读过措辞不能报告“每条独立数学证明通过”；只改页码也不能继承一轮全书数学审计的完成标记。

## 转换脚注或调整样式

转换前提取注记基线：完整文本和公式、原书位置参数、顺序、编号方式、引用、锚点及其与正文的关联。转换后对照这些内容，检查非注记正文、图形和个人批注仍在授权保护范围内。自动相等检查是回归证据，不能代替判断新的标记位置是否对应正确论述。

实际 PDF 至少要满足：

1. 每条译校注号与对应页底注释关联正确且同页，逐条核页码和目标。原书自身不可避免跨页的长脚注可按已选模板延续，须明确区分这种情形；续文完整且标识清楚，不能截断或误作新注。
2. 注释完整保留文字、公式和页码，页底没有裁切、碰撞、变色或正文覆盖；序号、重复号和链接目标正确。
3. 长证明、例题和跨页框内的注记真正排到页底。框内脚注可能被延迟释放或留在框里，必须看成书确认。必要时在同一逻辑条目内调整标记/释放位置，并记录关联，不能机械把所有框内注号迁到条目末尾。
4. 公式后标记、框后标记、证明结束符附近标记不单独占行，不被推到下一页或附到错误公式；调整局部间距时不改数学本体。
5. 字体、注号、标题、正文和分隔线分别遵从当前项目配色；改变其中一项不自动改变其他项或个人蓝注。源书原有脚注与新增译校注可辨且编号规则清楚。

样式或语句变化引起分页时，重新核所有受影响注号与页底、整页和邻页。不要仅检查编辑过的几条宏；同一个脚注样式修改可能影响全书全部注记。使用机器清单检查条数、输出文字、注号与注释的页/目标，再实际查看全部受影响页底，重点放大长注、跨页框内注、公式后注和含图页。生成渲染图或联系表不能自动标为“已实际查看”。

没有设定所有书的固定注记数、配色、字号或同一宏实现。报告本书动态计数、实际查看范围、异常与处置；项目既有格式可以使用，只要关联和阅读结果经过验证。

## 交付与核查边界

将注记内容核验、源书数学核验、个人批注保护、脚注布局、链接检查和发布重建分开报告。记清哪些源页回查过、哪些注记只读过措辞、哪些问题仍未确认。

完成显式主文件构建后，核成书和链接；最终 ZIP 仍按 [独立重建要求](audit-evidence-and-release.md) 干净解压重编译。换色后页面文字和位置可能保持，脚注转换或改句则可能重新分页；使用与改动匹配的实际比对证据。不能把脚注专项通过写为全书数学正确性、译文完整性或新增补译完成。
