# Sage-Olive Template Reference

Use the bundled Sage-Olive template only after the user selects it for this task. Ask for the template at each new task as required by the main skill; do not apply a default from another project.
Every Sage-Olive project must include the random landscape cover generated by `fetch_random_cover.py`.

## Required Files

Copy the whole template directory into the output project:

```text
assets/templates/sage-olive-template/
  template.tex
  sage-math.sty
  portable-math-fonts.sty
  .latexmkrc
  compile.sh
  fetch_random_cover.py
  fonts/
  assets/cover/selected-cover.jpg|png
  assets/cover/cover-source.json
```

Do not reference files inside the installed skill from the output project.

Initialize `terminology.tsv` before validation. If the project contains any raster or TeX-native figure/diagram, also initialize and complete `figure-manifest.tsv` with `scripts/figure_manifest_ledger.py`.

## Required Adaptation

- Replace source/title/date/language placeholders with verified project metadata. For translator/tool credit, use confirmed values or explicitly override `\SageChineseEditor` and `\SageProductionTool` with empty values for anonymous/unconfirmed credit; do not inherit sample text from `sage-math.sty`.
- Keep any source-derived Latin-script title or subtitle in its original capitalization. The sample placeholder `\SageEnglishTitle` should be replaced with the actual English title case from the source, not an all-caps template string.
- `\addfontfeatures{LetterSpace=5}` on the Sage-Olive cover changes tracking only; it must not be treated as permission to change letter case. Do not put `\SageEnglishTitle` or other source-derived metadata inside `\textsc`/`\scshape`.
- Set `\SageChineseEditor` to the confirmed translator/editor display name and `\SageProductionTool` to the confirmed tool/model name. Anonymous credit may clear or hide the corresponding visible line according to the project choice. The validator option checks metadata; it does not automatically restyle or anonymize the PDF.
- Put the human contributor in `\SageChineseEditor` and the tool in `\SageProductionTool`; never use Codex or a vendor name as the human contributor.
- Run `python3 fetch_random_cover.py` once after copying the template for every new task. It records the source URL and image hash in the cross-project history at `~/.codex/pdf-to-chinese-tex-cover-history.json` (override with `PDF_TO_CHINESE_TEX_COVER_HISTORY`). Keep the downloaded cover stable unless the user asks to reroll it; rerolls exclude prior sources and hashes.
- If the execution sandbox blocks that history path, request write access only for the history file (and its parent when the file does not yet exist), then rerun the command. Do not switch to an unshared project-local history merely to bypass approval, because that would permit cross-project cover reuse.
- Do not omit `\MakeSageCover`, replace it with a local fallback, or claim completion without `assets/cover/selected-cover.*` and `assets/cover/cover-source.json`.
- Use `\MakeSageCover`, then `\MakeSageCopyright`, then usually `\MakeSageContents`.
- Keep the copyright page immediately after the cover and before contents.
- Keep the copyright block in the upper-middle zone: the bundled default uses `\\vspace*{0.23\\paperheight}` before the block. Adjust only when the project's metadata length requires it, preserving comfortable bottom whitespace.
- Keep the complete `portable-math-fonts.sty`, `fonts/manifest.json`, font files and licenses inside the project, loaded by relative paths. Do not use system-specific font names or silent fallbacks.
- Follow [font-policy.md](font-policy.md): Fandol Song for body/proofs/examples, Fang for theorem statements, Kai for terms, Hei with bold CMU Serif for section/environment headings; Song for notes and cover Chinese. Western text uses CMU Serif, mathematics uses Computer Modern/AMS/RSFS, with 12pt body and 1.3 line spacing.
- Preserve the landscape cover, colors, boxes and page geometry. Font roles do not authorize changing the template design. Verify the local font manifest and actual PDF font embedding, then inspect the role-specific sample pages.
- Use dynamic running heads: the inner/left side shows the current `section` number and title, while the outer/right side shows the current `subsection` number and title (for example, `1 全正性` and `1.2 m 维空间中 2-平面的 Grassmannian`). Keep them in the bundled body fonts, light gray, with the template's thin rule below the header. Do not replace them with static book-title or author text.
- Do not add packages or change styling unless the source requires it.

## Build

For PDF output, use the bundled `compile.sh` for ordinary drafts. For final PDF validation, run `scripts/validate_sage_project.sh PROJECT MAIN.tex [--keep-aux] [--allow-anonymous] [--without-contents]`; it audits terminology and bibliography mechanics, verifies the source manifest when present, precompiles the body twice, then runs an index when present and compiles twice again, preserves a JSON validation report, validates the figure manifest when figures exist, and renders figure-page contact sheets. When the user explicitly wants TeX only, skip this build validator and follow the source-only checks in [audit-evidence-and-release.md](audit-evidence-and-release.md#仅交付-tex-时).

Inspect the cover, copyright page, contents when present, representative text/formula pages, any figure pages, and the final page.

`--allow-anonymous` permits explicit empty translator/tool fields; source author/date/language checks still apply. `--without-contents` is only for a project where the user chose to omit contents. The validator never downloads a missing cover or changes shared cover history; initialize/freeze assets separately. Fixed compilation passes do not establish pagination convergence.
