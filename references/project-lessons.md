# 三个数学译稿项目：可复用经验与适用边界

这些规则来自《箭图表示与箭图簇》《结合代数表示论基础》与 τ-倾斜理论项目的实际用户纠偏。提炼时已区分原始要求、历史完成声明与当前可读的验收证据；不把历史验收称为本次重新数学审计。使用本文件时仍以当前任务和最新授权为准。

| 实际问题 | 改善工作的方法 | 不应泛化的项目选择 |
|---|---|---|
| 高清透明截图保留了 `and rotations` 普通说明 | 图形几何、普通文字翻译分别验收；数学记号与专名分类保留 | 全图统一 600 dpi 截图 |
| 参考字体模板时误动框线/底色 | 字体、字号、行距、段距、框线、底色、末符分别记录允许差异；检查 PDF 实际字体角色 | 某书的 12pt、1.3/1.32 行距或颜色 |
| 英文名派生词被还原成人名词形 | 记录原词及用户要求，区分姓名、派生形容词与普通术语；同步显示层 | 所有书强制采用同一专名译法 |
| 流畅译句丢掉对象所属范畴、有限维限定或量词 | 源文逐段核对象类型、定义域/陪域、假设范围及推理方向；中文审校另作一遍 | 把中文通顺认作数学正确 |
| 同一“设/假设”反复引入，或把普通并列都写成“且” | 分清引入对象、附加条件、构造、记号和逻辑合取；不改“归纳假设”“当且仅当” | 全文机械 `假设→设`、`且→和` |
| `presentation` 与 `representation`，tame 与 gentle 等相混 | 查源词、定义及上下文；近义统一与真正误译分开记；同英文不同语义分别登记 | 某项目词表即全国统一标准 |
| 逐项补漏候选已在相邻正文出现 | 追加前读相邻定义、正文和公式，核内容是否已覆盖，避免重复插入 | 单句对照足够判定整段缺译 |
| 仅扫 TeX 图形，未发现原书整张缺图 | 从原书与译稿建立双向清单，覆盖 raster、TikZ、XY-pic、行内箭图及正合列 | 仅统计 `includegraphics` 即关闭图表审计 |
| PNG 文件正确但最终 PDF 使用次序/透明蒙版异常 | 检查最终 PDF 实际使用的图、页位置、尺寸与透明背景；改图页及邻页复验 | 哈希正确即成书正确 |
| “只修已有内容”与“完整译本”混为一谈 | 明确覆盖范围、暂缓习题/整块缺译、当前实际完成的维度 | 定点完成必须先补全所有历史缺译 |
| 原书更正先只写报告，后来获准改正文加注 | 继承最新授权；已证实原书错误、译稿错误、疑点与个人注分开 | 永久只写报告或永久全部用蓝字 |
| 注记混入构建/归档说明，脚注被长框延迟到后页 | 读者注写原文、定位、修正理由；过程放报告；核全部标记与脚注的对应、完整性和页底布局 | 每本书相同脚注颜色或同一种移标记方案 |
| 缓存旧 PDF 与当前源码不同步 | 以当前源码建立可比基线；旧 ZIP 不覆盖后来编辑；稳定索引后再比较 | 沿用历史页数或旧 passed 标记 |
| ZIP CRC 通过但索引/依赖只能在原目录构建 | 最终 ZIP 在新目录用包内材料独立编译，比较页面、文本、链接、目录及目标 | 固定编译五遍或二进制 PDF hash 必须相同 |

## 校准用例

下面是由真实问题改成的合成场景，用于检查本 skill 的行为边界，不是三本书的原文摘录，也不是已运行的测试成绩。

1. 用户说“只把环境显示名中文化”。应改变可见 `Definition–Proposition`、`Proof` 等，保护正文、蓝字、公式、键与计数器；不重换模板或补署名。
2. 源文是 `P only if Q`，错误候选“只要 Q，就有 P”反转了方向；正确关系是 `P ⇒ Q`，可译为“只有 Q 成立，P 才成立”或“若 P 成立，则 Q 成立”。中文通顺不证明逻辑正确，须按原文复核。
3. 原稿“设 X 是一个对象，假设 X 满足条件 C”。可根据原文合并为一次设定；不得省掉 C。“在归纳假设下”仍保留名词。
4. 用户说“图只替换英文，其他保持”。只改普通语言层；`Ker`、`Spec`、数学标签或未授权人名不随普通英文一起翻译；裁图不能带邻近正文。
5. 用户已授权原书勘误改正文并加注。核实后执行，注记给原写法、位置和理由；不再用早期“只写报告”阻止同一授权工作。
6. 用户明确“不要子智能体”。该任务独立完成；不将某次执行偏好保存成所有未来项目永久禁止并行。

具体术语、样式参数、页数和源版本只进入对应项目台账。向用户报告“扫了多少项”“改了多少片段”时，区分逻辑条目、实例、变化页和独立错误；累计记录可能重叠，不把片段数换称为错误数。
